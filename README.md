# Auto Tab Grouper — support

Public support for the [Auto Tab Grouper](https://chromewebstore.google.com/detail/cefpnhkapagecpalfnkjbbccmgpdaimn) Chrome extension. The extension's source code is kept in a private repository.

- **Problems and ideas:** [open an issue](https://github.com/harlinskyi-k/auto-tab-grouper-support/issues/new/choose).
- **Security reports:** privately, through the [Security tab](https://github.com/harlinskyi-k/auto-tab-grouper-support/security) or by email — see the [security policy](https://harlinskyi-k.github.io/auto-tab-grouper-support/security/). Please don't post vulnerabilities as public issues.
- **Privacy policy:** https://harlinskyi-k.github.io/auto-tab-grouper-support/privacy/

The pages are published with GitHub Pages from this repository: [`privacy.md`](privacy.md), [`security.md`](security.md), [`index.md`](index.md).
